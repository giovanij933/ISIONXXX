ISIONXXX // UI components

Shared, accessible components for the ISIONXXX apps. Load ui.css and ui.js, call UI.mount(root) once, render with the functions below, and listen for ui-change. Components hold no state: your app keeps it and renders again.

<link rel="stylesheet" href="ui.css">
<script src="ui.js"></script>
UI.mount(document.body);
document.body.addEventListener('ui-change', e => { state[e.detail.name] = e.detail.value; render() });

Interact with any example: its ui-change event shows here.

card

One app's summary. The title is a real button stretched over the card (opens the app); actions stay separate controls, so nothing interactive is nested. Fires a normal click on [data-open] / [data-go][data-act].

meter

{label, value, max, display?} — a progressbar with its value as text. Missing or non-numeric values show "—" and an empty bar; past the goal it fills and turns green.

week

{days:[{date, state}], label?, words?} — states: '' · on · half · pos · neg · live. Each day is read out ("Tue: done"); the last day is Today.

segmented · rating

segmented({name, label, options:[{value,label,hint}], value}) and rating({name, label, min, max, value, words}) are radio groups: Tab in, arrows / Home / End to choose.

choiceList

{name, label, options:[{value,label,detail,disabled}], value, multiple?}. One pick = radio group (dot); multiple:true = checkboxes (tick box), Space toggles. Long labels wrap; empty options show the empty text.

stepper

{name, label, value, min, max, step, unit} — the value is a spinbutton: Up / Down, Page Up / Down (×5), Home / End. Buttons disable at the limits.

button · loading · empty · toast

button({label, act, variant, busy, disabled}) — busy keeps the width, shows a spinner, sets aria-busy and blocks clicks. skeleton({label, lines}) announces loading once. UI.toast(text) is read politely by screen readers.

In place of the browser's confirm() and prompt(): UI.undo(text, fn) for a delete that happens at once (an Undo button, or ⌘Z, for 6 s); UI.confirm({title, body, ok, danger}) → Promise<boolean> for what can't be undone; UI.ask({title, body, value}) → Promise<string|null>. Both sheets close on Escape, a tap outside or a swipe down, and give focus back.
